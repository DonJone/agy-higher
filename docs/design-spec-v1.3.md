# agy-higher 设计规范 (v1.3 — 极简四阶同色系定稿)

## 1. 视觉与色彩铁律：同色系四阶上限

全产品严禁出现任何彩色点缀（无琥珀色、无绿色、无蓝色），严格限定在同一中性灰阶的 **4 个明度阶梯** 内：

- **深色模式（4 阶）**：
  1. `#121317` — 画布底色
  2. `#1B1D22` — 冰瓷舞台与容器基底
  3. `#7A808B` — 次级文字与普通并行会话灰点
  4. `#FFFFFF` — 主文字、VP 会话白点、主按钮与进度条填充
- **浅色模式（4 阶）**：
  1. `#FFFFFF` — 画布与浮起卡片
  2. `#F6F7FA` — 冰瓷舞台与内凹背景
  3. `#8A8F99` — 次级文字与普通并行会话灰点
  4. `#121317` — 主文字、VP 会话墨点、主按钮与进度条填充

## 2. 会话区分模型：仅 VP 会话 vs 普通并行会话

- 彻底取消「主从会话」「职责标签」「层级下拉」与一切虚假连接拓扑。
- 在目录树（含次级文件夹分组）与费用列表中，仅通过 **白点 / 墨点（VP 会话）** 与 **灰点（普通并行会话）** 区分会话权重；选中会话卡片右上可一键切换 VP 状态。

## 3. 三区域极简信息架构

- **Zone 1（左侧）**：统一 Finder 目录树（从 `/Users/don` 向下挂载），组合作为项目目录内的**次级文件夹**自然展开，列表仅呈现 `圆点 + 真实会话名 + 上下文百分比`。
- **Zone 2（右侧）**：彻底剥离嘈杂元信息，严格收敛为 3 张纯净卡片：
  1. **账户额度面板**：当前账户、剩余额度百分比、重置周期、单色进度条与 `切换账户` 入口。
  2. **当前文件夹会话消费**：当前目录或次级文件夹下所有会话的累计消费金额与各会话消费明细（点击即可切换选中会话）。
  3. **选中会话的上下文信息**：当前会话标题、VP/并行切换、`终端` 与 `打开 /r` 桥接操作、`/context` 进度条与明细（Rules / Skills & MCP / 对话 / 剩余）及 `/compact`、`/fork`、`复制链接`。
- **Zone 3（顶部 `CLI 配置`）**：账户切换、目录挂载点、`agy remote-control` 守护控制与 `~/.gemini/antigravity-cli/settings.json` 官方边界策略开关。
